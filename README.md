# La Petite Fleur au Café – Website

Vollständig optimierte Website für **SEO**, **AEO** (Answer Engine Optimization) und **GEO** (Generative Engine Optimization).

## Enthaltene Optimierungen

- **Schema.org JSON-LD** (LocalBusiness, CafeOrCoffeeShop, Florist, FAQPage, AggregateRating, OpeningHours, Geo)
- Semantisches HTML5
- Optimierte Meta-Tags (Title, Description, Open Graph, Twitter Cards, geo)
- FAQ-Sektion für Featured Snippets und AI-Antworten
- Lokale Keywords (Mannheim Q4, Café, Florist, Brunch)
- Mobile-responsive Design
- Schnelle Ladezeit (leichtgewichtiges HTML/CSS)
- robots.txt + sitemap.xml

## Deployment

1. Lade den Ordner auf einen Webserver oder Hosting (z.B. Netlify, Vercel, GitHub Pages) hoch.
2. Weise die Domain **lapetite-ma.com** darauf.
3. Aktualisiere in index.html die canonical URL und OG-URLs falls nötig.
4. Reiche die Sitemap bei Google Search Console ein.
5. Optimiere parallel das **Google Business Profile**.

Die Website ist ready to go und stark für Suchmaschinen und KI-Systeme optimiert.
